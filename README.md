# 橡樹小歌本

把橡樹幼兒園的兒歌與 CTP 小書整理在同一個 PWA。

- 首頁「兒歌」：搜尋、收藏及新增歌曲，並保留學校分享的原始資料入口。
- 「小書」：依小班／中班／大班及上下學期選擇 CTP 小書，開啟各版音檔。

此專案是純靜態網站，不需建置步驟。GitHub Pages 可從 `main` 分支的根目錄發布。發布後的入口是 `https://pmebruce.github.io/oaktree-song/`，小書區是 `/books/`。

App 外殼可離線開啟；Google Drive、YouTube 等外部音檔仍需網路。使用者新增的歌曲、最愛與備註保存在目前瀏覽器，可從「管理歌單」匯出備份。變更網站網址或手機時需自行匯入備份。
